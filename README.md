# RELAY — Free Contest Stack

Personal incident-response agent via iMessage.

**$0 stack:**
- Photon Spectrum Cloud (iMessage)
- Google Gemini Flash (free tier)
- Vercel Hobby
- Supabase Free
- Demo flight engine

## Features
- Signed Photon webhook
- Lazy Supabase client (builds cleanly)
- Gemini agent with function calling
- Application-enforced confirmation state machine
- Demo flight ranking (BEST / FASTEST / CHEAPEST)
- Allowlist for your phone number
- No real bookings or payments

## Quick start

1. `npm install`
2. Copy `.env.example` → `.env.local` and fill in values
3. Run the SQL in `supabase/schema.sql` in your Supabase project
4. `npm run build` (should succeed)
5. `npm run dev`
6. Open `http://localhost:3000/api/health`
